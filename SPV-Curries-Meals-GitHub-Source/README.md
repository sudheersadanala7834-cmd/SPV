# SPV Curries & Meals Website

A responsive, Andhra-inspired restaurant landing page with a 4-image animated hero slideshow.

## Preview locally
Open `index.html` in Chrome or Edge. An internet connection is required for Google Fonts and the remote food photographs.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` (keep its name exactly as `index.html`).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and open the URL shown there.

## Update photos
The four slideshow photos are loaded from Unsplash image URLs in the `.hero .slides` section of `index.html`. Replace each image URL with your own hosted photo URL when you have actual SPV food photos.
